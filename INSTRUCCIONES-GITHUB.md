# HPR Digital — publicación en GitHub Pages

1. Descomprime este ZIP.
2. Abre GitHub y crea un repositorio nuevo (por ejemplo `hpr-digital`).
3. Selecciona **Add file > Upload files** y arrastra el contenido de esta carpeta, no el ZIP.
4. Confirma los archivos con **Commit changes**.
5. En **Settings > Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`; guarda.
6. Espera a que GitHub muestre el enlace publicado.

## Antes de publicar
- Revisa datos personales, enlaces, WhatsApp, fotografías y CV.
- Verifica que todos los enlaces, formularios y funciones de la tienda funcionen.
- Los PDF comerciales deben permanecer fuera del repositorio público.
- Este sitio no procesa pagos automáticamente; las compras se coordinan por WhatsApp.
