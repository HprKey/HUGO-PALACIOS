# HPR-KEY · Portafolio y Academia Digital

Sitio oficial de Hugo Palacios: servicios web, proyectos y **HPR-KEY Digital Academy**.

**Sitio:** https://hprkey.github.io/HUGO-PALACIOS/

## Estructura
- `index.html`: portafolio, servicios, academia y carrito.
- `css/style.css`: diseño adaptable.
- `js/main.js`: navegación, proyectos, contacto y WhatsApp.
- `js/store.js`: catálogo, precios educativos, carrito y pedidos por WhatsApp.
- `js/projects.js`: portafolio y demostraciones.
- `assets/images/portada-ia-hpr-key.svg`: portada ilustrada del primer producto.
- `vista-previa-ia.html`: muestra educativa gratuita, sin contenido premium.

## Política comercial
Los servicios web **no muestran precios** y se cotizan por WhatsApp. Los productos educativos muestran precios y cantidades en el carrito. Los pedidos se envían como mensajes prellenados; no hay cobro ni confirmación automática.

## Editar
Actualiza el número de WhatsApp en `js/main.js` y `js/store.js`. Edita los productos en el arreglo `products` de `js/store.js`. Mantén los PDF completos **fuera del repositorio público**, incluyendo GitHub Pages.

## Publicar
GitHub Pages publica la rama `main` desde la raíz. Para revisar una propuesta, crea una rama, abre un pull request y fusiona a `main` solo cuando apruebes los cambios. El sitio se actualizará tras el despliegue.

## Verificar antes de publicar
Comprueba menú móvil, servicios, botones de WhatsApp, buscador, carrito, vista previa y formulario. No se han integrado pagos automáticos.
